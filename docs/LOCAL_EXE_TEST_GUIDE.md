# 本地 EXE 验收指引（G2）

本指引分为本地安装冒烟与受控真实平台验收。默认只做本地冒烟；最终发布必须使用明确授权的专用测试账号和测试内容。

## 测试前提

- 使用 Windows 测试电脑和测试账号。
- 已安装 Chrome 或 Microsoft Edge。
- 不使用真实商户账号；不扫描或输入非测试用途账号。
- 当前安装包为未签名开发包，Windows 安全提示需按内部测试流程处理。

## 验收步骤

1. 安装并启动发布助手；无有效会话时必须先显示独立商户登录页，不能直接进入业务主框架。
2. 使用与网页客户端相同的本地测试商户账号登录。单工作区直接进入；多工作区先显示选择页，切换商户不得串用任务或媒体资料。
3. 打开“媒体账号”，新增带备注的头条或抖音账号。确认每个账号使用独立浏览器资料目录，平台网址属于官方域名。
4. 使用专用测试账号完成扫码并点击“验证并备份会话”。网页端只应显示备份存在性和时间，不能显示 Cookie、Web Storage、密文或包装密钥。
5. 关闭并重启助手，确认商户会话、任务摘要和媒体账号状态可恢复；平台会话过期或风控时应回退扫码，不能伪造连接成功。
6. 在网页客户端创建测试发布任务，确认指定文章版本、平台和媒体账号准确；同一商户逐条执行，不同商户工作区可并行同步。
7. 仅在受控真实平台阶段观察自动下载图片、上传、填写、关闭白名单提示、最终提交和官方公开链接回传。验证码、短信、风控、页面变化或结果不明必须停止。
8. 对结果不明任务，先到平台作品列表人工核验；已发布时只能填写同平台官方公开链接确认成功，不能一键重发。未找到作品时保持阻断并记录证据。
9. 卸载开发包，确认主程序和卸载器移除。不要手工删除未知用户资料目录；生产卸载保留策略仍需单独确认。

## 记录项

- Windows 版本、Chrome/Edge 版本、安装包版本。
- 每一步成功/失败、用户可见提示和截图。
- 平台页面是否出现验证码、风控、改密或设备验证。
- 绝不记录二维码、Cookie、Token、账号密码或浏览器资料路径。

## 已完成的本地系统验收边界

- 已在本地 API 验收任务领取、设备租约、文章版本快照、两平台适配器调用链、官方链接回传、会话加密备份/恢复和异常状态机；这些仍不替代真实平台最终提交验收。
- 正常自动成功回传要求当前设备持有有效租约且适配器取得同平台官方公开链接。结果不明后的人工核验使用独立接口和审计，不会触发平台发布或自动重试。

## 当前不验收的能力

- 专用真实头条/抖音账号的最终提交、公开链接识别稳定性和平台改版兼容性。
- 真实设备 A/B 跨电脑恢复后的平台风控结果；代码链路通过不代表平台一定接受恢复会话。
- 验证码、短信、设备确认等平台安全机制的自动绕过；系统必须暂停并由人工完成。
- 生产 KMS、代码签名、正式 HTTPS 更新源、灰度与回退。
