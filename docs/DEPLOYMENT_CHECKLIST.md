# 部署前检查清单

本清单用于本地验收完成后的独立部署阶段。当前项目尚未授权部署服务器；任何一项未完成时，域名和更新策略必须保持停用。

## 1. 基础环境

- [ ] 独立生产 PostgreSQL、Redis、对象存储和备份保留策略已确定。
- [ ] 生产环境变量由受控密钥系统注入，未写入仓库、镜像、日志或前端构建产物。
- [ ] API、Worker、静态站服务和反向代理使用独立最小权限身份运行。
- [ ] Worker 有单实例/并发控制、健康检查、重启和模型费用告警。
  - 代码已提供 `AI_WORKER_CONCURRENCY`、`DOUBAO_WORKER_CONCURRENCY`、30秒TTL心跳和 `/api/health/ready`；生产必须设置 `HEALTH_REQUIRE_WORKERS=true` 并接入摘流/重启/告警后才可勾选本项。
- [ ] 数据库迁移已先在备份副本演练；禁止通过删除表或重置数据库升级。

## 2. 域名与网站

- [ ] 四类入口域名分别配置：总后台、贴牌/代理后台、商户客户端、企业内容站根域名。
- [ ] 每条自定义域名已完成 DNS 所有权验证、TLS 证书、网关路由和静态文件访问验证。
- [ ] 内容根域名启用后已重新生成受影响企业站，并检查 canonical、robots、sitemap 与结构化数据。
- [ ] 未验证、证书异常或已停用域名不会被分配给商户网站。
- [ ] 贴牌 OSS/CDN 已通过隔离探针的写入、读取、公开 URL 读取与清理验证。

## 3. 模型与费用

- [ ] 每个贴牌自行提供并测试已开通的写作和豆包检测模型配置；平台不保存或回退使用其他贴牌 Key。
- [ ] 已在隔离环境确认写作模型与实际模型 ID 可调用；当前开发验收使用过 `deepseek-v4-flash-ga-260731`，正式贴牌不得照抄开发配置，必须以其自有已开通模型为准。
- [ ] DeepSeek/兼容接口的准确模型 ID、限流、超时和预算已确认。
- [ ] 豆包检测的“名称命中”展示明确标注为业务口径，不表述为豆包 App 官方收录。
- [ ] 全部商户检测启用前已确认调用量预览、二次确认、并发、退避和失败续跑策略。

## 4. 发布助手

- [ ] 仅使用获得授权的头条/抖音测试账号，验证扫码登录、账号级会话恢复、素材自动下载与上传、内容填写、已知非风险提示关闭、最终自动提交和官方公开链接回传。
- [ ] 同一商户同平台多个媒体账号使用独立资料目录和独立加密会话；同一商户串行、不同商户受控并行，任务不得串账号或串租户。
- [ ] 只允许上传经过平台域名白名单、结构校验和大小限制的版本化可移植会话包；包内 Cookie、LocalStorage、SessionStorage、IndexedDB 必须由平台 KMS 信封加密，后台、网页端和日志均不可读取明文。
- [ ] 二维码、平台账号密码和完整浏览器资料不得上传；验证码、设备风控或提交后结果不明必须暂停自动流程，已知非风险提示可以自动关闭。
- [ ] 发布成功只接受自动识别的官方公开链接并幂等回传；结果不明时禁止自动重发，人工只能核验“已发布”并补录官方链接，不能作为正常发布流程。
- [ ] 已验证设备 A 保存、设备 B 恢复、撤销失效以及恢复失败退回扫码；不得承诺通过会话迁移绕过平台设备风控。
- [ ] 正式安装包已完成 Windows 代码签名、干净 Windows 安装/升级/卸载验收。
- [ ] 更新源使用受控 HTTPS；同版本安装包、`latest.yml`、`blockmap`、SHA-256、灰度范围和回退包完整对应。
- [ ] 总后台更新策略默认关闭，只有上述条件全部完成后才可开启。

## 5. 上线前回归与恢复

- [ ] `pnpm check` 与隔离写入型集成验收通过。
- [ ] 执行四角色登录、横向/纵向越权、开户额度、域名状态、模型禁用、对象存储失败、发布租约和电话事件回归。
- [ ] 生产备份与恢复在非生产副本成功演练；记录恢复目标时间和恢复点目标。
- [ ] 发布后健康检查、错误告警、审计日志、模型/存储费用和 Worker 队列监控已配置。

完成清单不代表可以跳过业务内容真实性、平台规则、广告法和隐私合规审核。
