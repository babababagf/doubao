## 当前目标

按 2026-08-10 最新决定，开发主顺序固定为三步：第一步普通商户网页客户端；第二步 EXE 发布客户端；第三步后台管理体系（总后台、贴牌后台、代理后台）。当前只推进第一步及其必要真实 API；用户验收第一步前冻结第二、三步的新增开发。全部先在本地验证，不直接部署服务器。

当前网页客户端已达到“本地验收候选”：10 个第一阶段业务页面均接通真实 API，文章支持结构化富文本编辑、手动新增、0～3 张图库配图和版本快照，三套网站模板可生成本地静态站。真实 DeepSeek 已完成“公司名 + 关键词、无信息库、无图库”的文章生成并直接进入可发布列表。公网域名分发与真实 OSS/CDN 仍属于部署边界，不阻塞本地网页客户端验收；“媒体账号”和“发布任务”属于第二阶段 EXE 联动范围，默认从第一阶段菜单隐藏。

EXE 现有源码、安装包和测试记录保留，不删除、不继续开发；本轮已停止本地发布助手进程。此前加入的自动发布联调文章与图片是明确标记的本地测试数据，未经用户确认不删除。

## 已确认产品规则

- 四级关系：总后台 → 贴牌 → 代理 → 普通商户；代理只能开普通商户。
- 总后台单独入口；贴牌/代理共用入口并由后端权限控制；网页客户端单独入口。
- 系统昵称与 Logo 只允许总后台设置；代理和普通商户继承所属贴牌。
- 贴牌自备并承担模型、豆包检测、OSS/CDN 费用；代理与商户只能调用所属贴牌资源；服务器由平台提供。
- AI 拓展一个新增问题词扣 1 点；AI 成功生成一篇文章扣 30 点及 1 篇写作额度；发布不限篇数。
- 商户仪表盘只展示：问题总量、豆包收录数、电话曝光量、电话点击量；“豆包收录数”只能表示 API 回答命中公司名或简称的问题数量。
- 网站一商户一站、三套模板、静态优先；不做城市分站/关键词站群。页面主要正文、联系方式必须无需前端脚本即可读取。
- 联系电话统计不是随机数：只有网页实际显示电话时才可统计曝光与点击。
- 下级账号密码严格按用户规则：6–12 位、只允许英文字母或数字。
