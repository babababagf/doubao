## 本地复现

```powershell
docker compose -f infra/docker/compose.yaml up -d postgres redis
pnpm --filter @doubaohk/api db:generate
pnpm --filter @doubaohk/api exec prisma migrate deploy
pnpm --filter @doubaohk/api db:seed
pnpm check

# 另开终端：正常 API、隔离 API、Worker
pnpm --filter @doubaohk/api start
pnpm --filter @doubaohk/api start:isolated-test-api
pnpm --filter @doubaohk/api start:worker

Invoke-RestMethod http://127.0.0.1:3010/api/health/live
Invoke-RestMethod http://127.0.0.1:3011/api/health/live

# 隔离库写入型验收
$env:LOCAL_API_INTEGRATION_WRITE='true'
$env:LOCAL_API_URL='http://127.0.0.1:3011/api'
pnpm --filter @doubaohk/api test:integration
```

演示账号仅用于本机：商户 `demo001 / demo123`、总后台 `admin001 / admin123`、贴牌 `tenant001 / demo123`、代理 `agent001 / demo123`。

## 已知限制

1. DeepSeek 已完成带信息库和“仅公司名 + 关键词、无信息库、无图库、0 配图”两种真实写作验收。按最新产品决定，模型成功返回非空且未超过系统容量上限的文章后直接进入可发布列表，不再因字数、标题结构、关键词密度或企业名次数执行硬性拒绝或二次纠偏；商户可自行编辑、停用或删除。第三方模型仍可能偶发超时，失败任务不会入库并会释放预占；正式环境必须由贴牌自行配置、测试并启用资源，平台不承担模型算力或承诺提供方 100% 可用。
